# Producto implementado

Sistema PMS ultra liviano con secciones exactas:
- Calendario
- Reservas
- Hoy
- Limpieza
- Reseñas
- Ajustes

Incluye:
- Gestión de hotel único por usuario.
- Habitaciones, reservas, bloqueos, limpieza.
- Flujo de check-in/check-out con efectos automáticos.
- Motor de reseñas con WhatsApp + landing pública por token.
- Exportación CSV de reservas.

No incluye integraciones extra ni funcionalidades fuera del alcance.
